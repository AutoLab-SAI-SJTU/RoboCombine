# Metadata

This repository is a code-only open-source evaluation runtime.
It does not ship public dataset-release metadata in the tracked source tree.

If you need local archival drafts such as Croissant, DCAT, schema.org, or
release-manifest templates, keep them under `metadata-private/`.
That directory is local-only and intentionally ignored.

The repository-level release check validates the code-only source tree without
requiring dataset cards, Croissant metadata, or archival DOI metadata.
